# Netflix Insight Engine 📺

## 🚀 Overview

Netflix Insight Engine is a data analytics project that explores Netflix's content catalog to uncover trends in movies, TV shows, genres, countries, and platform distribution.

Using exploratory data analysis (EDA) and visualization techniques, the project transforms raw Netflix data into meaningful insights about content availability and viewing trends.

---

## 🧠 Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📊 Features

- Netflix dataset exploration
- Movies vs TV Shows analysis
- Country-wise content distribution
- Genre popularity analysis
- Missing value assessment
- Data visualization dashboards
- Descriptive statistics generation

---

## 📂 Dataset Information

The dataset contains information about Netflix titles including:

- Title

- Release Year
- Rating
- Duration

- Description

## ⚡ Analysis Performed

### Content Type Distribution

Analyzed the proportion of:

- Movies
- TV Shows

### Country Analysis

Identified countries with the largest number of Netflix titles.

Top contributors include:

1. United States
2. India
3. United Kingdom
4. Japan
5. South Korea

### Genre Analysis

Explored the most common content categories and genre combinations available on Netflix.

### Data Quality Assessment

Investigated missing values across important dataset columns.
